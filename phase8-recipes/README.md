# Phase 8 recipes in-game

Every recipe from #228, plus the Material Upgrade Tool recipe from #229, shown in a vanilla crafting table (and a smithing
table for the Netherite wall). Taken on NeoForge from a local merge of both PR branches.

`recipes.txt` opens the tables and fills each grid on the server; the result slot is what the game computed from the
loaded recipes, and each eval prints it. Tag ingredients are shown with one member: oak planks for any planks, oak log
for any log, the wooden wall for any plain wall.

`recipes-overview.png` has all of them with labels; `recipe-<id>.png` are the full screenshots.
