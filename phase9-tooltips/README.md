# Phase 9 tooltips

`tooltips.txt` gives an iron wall and a netherite core in survival and opens the inventory. The tooltips read:

- Iron Chest Wall: "Chests up to 5x5x5, upgrade slots: 3", "<Shift for info>"
- Netherite Chest Core: "Chests up to 10x10x10, upgrade slots: 7", "<Shift for info>"

The shift text itself can not be shown here, as the client reads the physical shift key.
